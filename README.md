# Muwoni Task Manager

A web-based task management application built with **Django** that helps users organize their daily activities through a simple and intuitive interface. The application includes task management features, calendar integration, and an overview of **Muwoni Technologies**, reflecting the company's vision of building practical software solutions.

## Features

- Create, update, and delete tasks
- Calendar integration for task scheduling
- Responsive user interface
- Clean and intuitive design
- Information page about Muwoni Technologies
- Deployed using Render

## Installation

Clone the repository:

```bash
git clone https://github.com/big21josh/muwoni-completed-project.git
```

Navigate to the project directory:

```bash
cd muwoni-completed-project
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment.

**Windows**

```bash
venv\Scripts\activate
```

**macOS/Linux**

```bash
source venv/bin/activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Apply database migrations:

```bash
python manage.py migrate
```

Start the development server:

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
